hakuX-lr against an Xbox, test by test

Each test draws one picture through the NV2A's graphics engine. Its picture from hakuX-lr is compared with the same test's capture from a real Xbox 1.0. A test matches when under 0.5% of its pixels differ, is close under 5%, and is different otherwise. A pixel differs when a colour channel is more than 20 of 255 away; alpha is ignored, as the console's video output ignores it.

How this was run

hakuX-lr master (aa12ea0), 2026-11-19. RetroArch 1.22.2 on x86-64 (Linux, KVM), one run for each render scale (1x, 2x, 4x; 1x is the Xbox's resolution) and pipelines built before their first draw (HAKUX_HLE_ASYNCPIPE=0), so no draw is skipped while a shader compiles; other core options at their defaults. nxdk_pgraph_tests release v2026-11-15_17-02-26-210881655 with a config on the disc that starts the run at once; the hardware captures are abaire/nxdk_pgraph_tests_golden_results.

At 2x and 4x hakuX-lr renders at a multiple of the Xbox's resolution; the tests save their pictures at the Xbox's, so the comparison is with the same hardware captures.

Tests the capture set marks as deprecated are left out: the suite no longer contains them.

Some tests save more than one picture, so the counts are pictures. A suite whose pictures hakuX-lr never wrote is listed under "not run".
