hakuX against an Xbox, test by test

Each test draws one picture through the NV2A's graphics engine. Its picture from hakuX is compared with the same test's capture from a real Xbox 1.0. A test matches when under 0.5% of its pixels differ, is close under 5%, and is different otherwise. A pixel differs when a colour channel is more than 20 of 255 away; alpha is ignored, as the console's video output ignores it.

How this was run

hakuX-lr master (0839cf0) with PR #233 (FIFO wait fix), 2026-11-15. RetroArch 1.22.2 on x86-64 (Linux, KVM), render scale 1x (the Xbox's resolution) and pipelines built before their first draw (HAKUX_HLE_ASYNCPIPE=0), so no draw is skipped while a shader compiles; other core options at their defaults. nxdk_pgraph_tests release v2026-10-31_21-06-59 with a config on the disc that starts the run at once; the hardware captures are abaire/nxdk_pgraph_tests_golden_results.

Tests the capture set marks as deprecated are left out: the suite no longer contains them.

Some tests save more than one picture, so the counts are pictures. A suite whose pictures hakuX never wrote is listed under "not run".
